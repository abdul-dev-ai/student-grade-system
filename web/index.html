THE GRADING POLICY

Every score, explained.

A score of 50 or above is a pass. Grade boundaries use the original score, before display rounding.

A80–100Excellent · Pass
B70–<80Very good · Pass
C60–<70Good · Pass
D50–<60Satisfactory · Pass
F0–<50Needs improvement · Fail

This is the assignment’s default policy, not an official university grading policy. Class statistics always include all records, even when the table is filtered.
DATA STRUCTURES IN ACTION

An array at the core.

The C++ engine owns one fixed array of 1,000 Student structs. The browser only presents the engine’s results and saves a JSON snapshot.

Student students_[1000];
std::size_t count_ = 0;
Insert & update
Linear duplicate-ID lookup · O(n)
Delete
Find, then shift records left · O(n)
Search & statistics
Traverse the active array · O(n)
Sort
Stable insertion sort · O(n²)

Grades, pass/fail, averages and distribution percentages run in C++ through WebAssembly. No database or JavaScript calculation fallback.
